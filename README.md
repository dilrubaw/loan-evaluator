# Loan Application Evaluation and Installment Calculation System

Java 21 · JUnit 5 · Maven · JaCoCo

## Structure
- `src/main/java/org/dlrb/loan` – application classes
- `src/test/java/org/dlrb/loan` – JUnit 5 test classes (76 tests)
- `reports/jacoco/index.html` – code coverage report (100% instruction, 100% branch)
- `reports/surefire-reports` – test execution results
- `pom.xml` – build configuration

## Run the tests
mvn clean test
